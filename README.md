# Edita Web Extension

A versatile, multi-purpose browser extension equipped with a wide variety of daily utilities and specialized tools. This extension is designed to boost productivity by providing calculators, format converters, text utilities, media tools, and much more right in your browser's side panel.

## 🛠️ Included Tools

Here is a comprehensive list of all the tools included in this extension, grouped by their category and purpose:

### 🧮 Math & Calculators

- **Calculator**: A standard calculator for basic mathematical operations.
- **Differentiation Tool**: Calculate derivatives of mathematical expressions.
- **Integration Tool**: Evaluate integrals of mathematical functions.
- **Logarithm Tool**: Calculate logarithms for various bases.

### 💰 Financial Calculators

- **Compound Interest Calculator**: Calculate the future value of your investments with compound interest.
- **FD Calculator**: Calculate returns on Fixed Deposits.
- **Mutual Fund Calculator**: Estimate returns on mutual fund investments.
- **PPF Calculator**: Plan Public Provident Fund (PPF) investments and calculate maturity values.
- **RD Calculator**: Calculate interest and maturity amount for Recurring Deposits.
- **SIP Calculator**: Calculate the potential returns of your Systematic Investment Plans.

### 📝 Text & Content Utilities

- **Character Counter**: Count the exact number of characters in a given text.
- **Word Counter**: Quickly count the number of words in a text block.
- **Sentence Counter**: Evaluate the number of sentences in your content.
- **Lorem Ipsum Generator**: Generate placeholder text for design and layout mockups.
- **Remove Duplicate Lines**: Clean up lists or files by removing identical recurring lines.
- **Text Case Converter**: Quickly change text casing (uppercase, lowercase, camelCase, Title Case, etc.).
- **Text Cleaner**: Strip out unwanted spacing, characters, and normalize text.
- **Text Sorter**: Sort lines of text alphabetically or numerically.

### 🔄 Format & Data Converters

- **Base Converter**: Convert numbers between binary, octal, decimal, and hexadecimal bases.
- **Color Converter**: Convert color codes between HEX, RGB, HSL, and other formats.
- **CSV to JSON**: Easily convert comma-separated values into JSON arrays.
- **JSON to CSV**: Flatten JSON data into CSV format for spreadsheets.
- **JSON to Excel**: Export JSON structures directly to Excel-friendly tabular formats.
- **JSON Formatter**: Prettify, format, and validate raw JSON strings.
- **Markdown to DOCX**: Convert Markdown documents into Microsoft Word format.
- **Markdown to Excel**: Convert tabular Markdown content into Excel spreadsheet files.
- **FML Converter**: Utility for parsing and converting specialized FML formats.

### 🖼️ Image & Media Tools

- **Image Cropper**: Crop images intuitively within the browser.
- **Image Resizer**: Resize images to specific dimensions easily.
- **YouTube Playlist Analyzer**: Retrieve and analyze useful metrics and video data from a YouTube playlist.
- **YouTube Thumbnail Downloader**: Extract and save thumbnails from YouTube videos.
- **Metadata Stripper Guide**: Guide and tool reference for safely removing hidden metadata from files.

### ⏱️ Time & Measurements

- **Stopwatch Timer**: A straightforward stopwatch and timer for tracking tasks.
- **Time Zone Matcher**: Compare and match different global time zones easily.
- **Temperature Converter**: Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- **Unit Converter**: Convert various physical units (length, weight, volume, etc.).

### 🎲 Randomizers & Generators

- **Coin Flip**: A simple digital coin flipper for quick binary decisions.
- **Roll Dice**: Roll virtual dice for games or random outcomes.
- **Spin the Wheel**: A customizable spinning wheel for random selections.
- **Password Generator**: Generate highly secure, random passwords with customizable criteria.
- **QR Code Generator**: Create a scannable QR code from any text or link.
- **UUID Generator**: Rapidly generate unique UUIDs (Universally Unique Identifiers) for development.

### 💻 Developer Utilities

- **Regex Tester**: Test regular expressions against string inputs to validate your patterns.

### 🎮 Interactive & Skill Testers

- **Mouse Accuracy Checker**: Test and track your pointer precision and clicking speed.
- **Typing Speed Test**: Evaluate your WPM (Words Per Minute) and typing accuracy.
